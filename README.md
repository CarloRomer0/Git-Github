# 🚀 Proyecto Final de Práctica en Git y GitHub

Este proyecto tiene como objetivo poner en práctica los conocimientos adquiridos a lo largo del curso, integrando:

- 🧠 Análisis
- 💡 Creatividad
- 🔧 Manejo de versiones con Git
- ☁️ Colaboración remota mediante GitHub

---

## 📁 Estructura del Repositorio

El proyecto contiene **4 archivos principales** de tipo Markdown:

| Archivo            | Descripción                                          |
|--------------------|------------------------------------------------------|
| `Informacion.md`   | Información personal y académica                     |
| `Proyectos.md`     | Lista de proyectos realizados con explicación clara  |
| `Clasificacion.md` | Preferencias personales clasificadas                 |
| `README.md`        | Este archivo que estás leyendo                       |

Cada archivo fue trabajado en su propia rama:

- `informacion`
- `Proyectos`
- `Clasificacion`
- `main` (rama final que reúne todo)

---

## 🔀 Flujo de Trabajo Usado

1. Se creó una rama por archivo.
2. Se realizaron **mínimo 6 commits por archivo**.
3. Se unieron las ramas a `main`.
4. Se subió todo a GitHub.
5. Se preparan pull-requests a proyectos de compañeros (forks).
